## 3. Investigation: Accuracy Discrepancy (0.87 vs. 0.8683)

### 3.1 Problem Statement
When running evaluation, the classification report text block displays accuracy as `0.87`:
```text
              precision    recall  f1-score   support

       <=50K       0.89      0.94      0.92      7497
        >50K       0.77      0.62      0.69      2274

    accuracy                           0.87      9771
   macro avg       0.83      0.78      0.80      9771
weighted avg       0.86      0.87      0.86      9771
```
However, the separate metric printed and saved to [`reports/final_test_metrics.csv`](file:///D:/incomelens-ai/reports/final_test_metrics.csv) is `0.8683` (`0.868283696653362`).

### 3.2 Root Cause Analysis
The scikit-learn function `classification_report` uses an optional keyword argument `digits` to control numeric precision:
```python
sklearn.metrics.classification_report(y_true, y_pred, digits=2)
```
- In scikit-learn, the default value for `digits` is **`2`**.
- Applying 2-digit half-to-even rounding to the exact float `0.868283696653362`:
  $$\text{round}(0.86828369..., 2) = \mathbf{0.87}$$
- In contrast, the evaluation script printed standalone metrics formatted with 4 decimal places (`{value:.4f}`):
  $$\text{round}(0.86828369..., 4) = \mathbf{0.8683}$$

### 3.3 Verification with `digits=4`
Executing `classification_report(y_test, preds, digits=4)` confirms:
```text
              precision    recall  f1-score   support

       <=50K     0.8906    0.9444    0.9167      7497
        >50K     0.7710    0.6174    0.6857      2274

    accuracy                         0.8683      9771
   macro avg     0.8308    0.7809    0.8012      9771
weighted avg     0.8627    0.8683    0.8629      9771
```
- **Finding:** Under 4-decimal formatting, the classification report accuracy displays as **`0.8683`**.
- **Verdict:** The difference between `0.87` and `0.8683` is **purely a presentation/rounding artifact** resulting from scikit-learn's default 2-digit report formatting. No data, prediction, or metric inconsistency exists.
